ClipJoiner

コマンドライン

形式が揃った複数の MP4 を並べ替え、映像を再エンコードせず1本に連結する。

ClipNormalizer

動画クリップ正規化

コマンドライン

MP4素材を、後で安全に連結しやすい同一解像度・CFR・ゼロ開始PTSの形式へ変換する。

使用例
python ClipNormalizer\clip_normalizer.py "input.mp4" "normalized.mp4" --fps 30 --width 1920 --height 1080
その他説明
既定は1920x1080、30fps、H.264/libx264、AAC 48kHz、CRF 18。縦横比を維持して黒帯で埋め、変換後にコーデック、寸法、FPS、開始時刻、音声を検証する。幅と高さは偶数が必要。
実行ファイル
ClipNormalizer/clip_normalizer.py
必要なもの
Python 3, FFmpeg, ffprobe

Time Lapse

音声付きタイムラプス生成

コマンドライン

動画と音声を指定倍率で高速化し、H.264/AAC の MP4 として出力する。
