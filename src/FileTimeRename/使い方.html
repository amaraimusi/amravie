FileTimeRename

ファイル日時付与ツール · Python 3.9以上

← ツール一覧

目次：概要 ／ 実行方法 ／ 引数 ／ 動作と注意点

概要

指定フォルダ内のすべての通常ファイルに、ファイルの更新日時を付与します。動画以外や拡張子のないファイル、隠しファイルも対象です。作成日時・動画内部の撮影メタデータは使いません。外部ライブラリは不要です。

MOV_0123.mp4
↓ 更新日時が2026年10月15日 09時30分25秒の場合
20261015_093025_MOV_0123.mp4

名前に日時が残るので、後日編集して更新日時が変わっても、付与済みの名前は維持できます。すでに更新日時が撮影日時から変わっている場合、元の撮影日時を復元する機能はありません。

実行方法

WindowsのPowerShellなどで実行します。パスに空白があっても使えるよう、引用符で囲んでください。

1. 変更予定を確認する（任意）

python "C:\Users\user\git\amravie\src\FileTimeRename\file_time_rename.py" "E:\backup_kenji\mov\n175\100ANDRO" --dry-run

2. ファイル名を変更する

python "C:\Users\user\git\amravie\src\FileTimeRename\file_time_rename.py" "E:\backup_kenji\mov\n175\100ANDRO"

サブフォルダ内も処理する場合は末尾に --recursive を付けます。

python file_time_rename.py "D:\動画フォルダ" --recursive --dry-run
python file_time_rename.py --help

引数・オプション

指定内容
directory（必須）対象フォルダ。通常は直下だけを処理します。
-r / --recursiveすべてのサブフォルダ内も処理します。フォルダ名は変更しません。
--dry-run変更予定とエラーを表示するだけで、ファイルを変更しません。
-h / --helpヘルプを表示します。

動作と注意点

  • バックアップは作成しません。ファイル内容は書き換えず、更新日時も維持します。
  • 日時は実行環境のローカル時刻です。日本時間で付与する場合は、PCのタイムゾーンを日本に設定してください。秒未満は名前に含めません。
  • 先頭に有効な YYYYMMDD_HHMMSS_ があるファイルは、更新日時と異なっていてもスキップします。従来の 26_0913_ などの接頭辞は残して、新しい日時を先頭に付けます。
  • 変更先と同名のファイル・フォルダがあれば上書きせず、そのファイルをエラーとして報告し、残りを処理します。長すぎる名前や権限不足なども同様です。
  • シンボリックリンクやジャンクションは処理・追跡しません。対象のルートフォルダにも実体のパスを指定してください。
  • 実行中は対象ファイルの編集・移動などを避けてください。途中でエラーや中断があっても、完了した名前変更は元に戻しません。再実行すると日時付きのファイルをスキップします。
  • 最後に変更（事前確認では変更予定）・スキップ・エラーの件数を表示します。終了コードは成功が0、一部失敗が1、引数の誤りが2、中断が130です。
