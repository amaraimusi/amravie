InstaThumbPad
サムネ余白メーカー

元サムネイルを拡大縮小せず、余白を付けた背景の中央に配置するPython 3用ツールです。背景だけを縦横比を保って拡大縮小します。

1. 初回の準備

Windowsのコマンドプロンプトで、次のコマンドを実行します。Python 3.9以上とPillowが必要です。

cd /d "C:\Users\user\git\amravie\src\InstaThumbPad"
python -m pip install -r requirements.txt

2. 実行方法

python insta_thumb_pad.py "背景画像" "元サムネ画像" ["出力画像"] 余白率
引数指定内容
背景画像背景に使う画像のファイルパス。
元サムネ画像中央に重ねる画像のファイルパス。
出力画像（省略可）省略時は元画像と同じフォルダに「元画像名_instapad.png」を作ります。指定する場合は余白率の前に置きます。
余白率元サムネ幅に対する左右合計の追加割合（％）。20で合計20％、左右それぞれ約10％です。数値のみ、0～1000、小数も使用できます。0.2は0.2％です。

3. テスト画像で試す

python insta_thumb_pad.py "back1.png" "サムネ45.png" 20

「サムネ45_instapad.png」を作成します。元サムネは1122×1402のまま、出力は1347×2393ピクセルです。

出力先を指定する例：

python insta_thumb_pad.py "back1.png" "サムネ45.png" "余白つき.png" 40

4. 実際のデータで使う

以下はご指定のパスを使った例です。ドライブとフォルダが存在する環境で実行してください。

python insta_thumb_pad.py "E:\backup\_kenji\mov\amaraimusi\_no\_utabako\common\back1.png" "E:\backup\_kenji\mov\amaraimusi\_no\_utabako\a028\シーンイラスト\サムネtk.png" 20

5. サイズの計算

出力幅 = 元サムネ幅 × (1 + 余白率 ÷ 100)（小数点以下切り上げ）。出力高さ = 背景の元高さ × 出力幅 ÷ 背景の元幅（最も近い整数に丸めます）。元サムネは上下左右の中央に置きます。余白が奇数ピクセルの場合、右・下が1ピクセル多くなります。

背景の高さが元サムネより小さくなる場合はエラーで停止します。縦長の背景に変更するか、表示された目安以上に余白率を増やしてください。元サムネの縮小・切り抜きは行いません。

6. 保存と注意点

  • 出力はPNG・JPEG・WebPに対応します。画質の劣化を避けるならPNGを使います。JPEGは非可逆圧縮で、透明部分は白になります。PNGとWebPでは透明部分を保持します。
  • 既存ファイルは上書きしません。再実行時は別の出力名を指定してください。元画像への上書きも禁止しています。
  • 相対パスはコマンドプロンプトの現在のフォルダが基準です。出力先のフォルダは先に作成してください。
  • EXIFの向き情報を反映してから配置します。アニメーション画像は先頭フレームを使用します。
  • メモリ使用量を抑えるため、出力は8000万画素までです。
  • Instagramでの表示結果を見ながら余白率を調整してください。表示枠によって必要な余白は異なります。
python insta_thumb_pad.py --help
