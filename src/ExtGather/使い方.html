ExtGather

拡張子別ファイル収集ツール

← ツール一覧

指定した拡張子のファイルを、探索対象フォルダのすべての下層から探し、出力フォルダの直下にコピーします。元ファイルは保持します。Python 3.9以上で動作し、追加ライブラリは不要です。

1. Windowsのコマンドプロンプトで実行

cd /d C:\Users\user\git\amravie\src\ExtGather
python ext_gather.py srt "E:\backup_kenji\mov" "E:\backup_kenji\mov\srt"

出力フォルダはなければ自動作成します。パスに空白がある場合は必ずダブルクォートで囲んでください。

コピー前に予定を確認するには、次のように実行します。

python ext_gather.py srt "E:\backup_kenji\mov" "E:\backup_kenji\mov\srt" --dry-run

--dry-run はファイルもフォルダも作成・変更しません。スキップ分は件数に含めます。

2. 引数

python ext_gather.py 拡張子 探索対象ディレクトリ 出力ディレクトリ [--dry-run]
python ext_gather.py --help
引数説明
拡張子srt と .srt のどちらでも指定できます。大文字小文字を区別しません。1回につき1種類です。
探索対象ディレクトリ存在するフォルダを指定します。直下とすべての下層を探索します。
出力ディレクトリ収集先。探索対象の下に置いても、このフォルダとその下層を探索から除外します。
--dry-runコピー・更新の予定と集計だけを表示します。

3. 同名ファイルの扱い

最初のファイルには元のファイル名を使用します。同名ファイルがあれば、元の名前__親フォルダ名__パスの識別子.srt のように変更します。それでも衝突すれば連番を加えます。出力先に元からある未登録ファイルの名前も避けます。

コピー元の絶対パスと出力名の対応を保存するため、後から同名ファイルが増えても、すでに収集したファイルの出力名は変わりません。コピー元の移動・改名は別ファイルとして扱います。

4. 繰り返し実行と更新日時

  • 出力ファイルがない場合はコピーします。
  • コピー元の最終更新日時が出力ファイルより新しければ上書きします。
  • 更新日時が同じ、または出力ファイルのほうが新しい場合はスキップします。
  • コピー時に元の更新日時を保持します。内容が変わっても更新日時が新しくなければ更新しません。
  • 元ファイルが削除されても、過去に収集したファイルは削除しません。

5. 出力フォルダの収集記録

README.md に、実行日時、今回の探索先・拡張子、件数、各出力ファイルのコピー元絶対パスと出力更新日時を記載します。過去の収集分も含みます。

.extgather.json は次回実行のための対応記録です。出力ファイルと一緒に保持してください。削除・編集すると対応を復元できず、追加コピーになることがあります。README.mdは実行のたびに再生成されるため、手書きメモは別ファイルに保存してください。

6. 注意点とエラー対応

  • 同じ出力フォルダを複数の実行から同時に更新することはできません。
  • 強制終了後に .extgather.lock が残ったら、他の実行が動いていないことを確認して、このロックファイルだけ削除してください。
  • シンボリックリンク、ジャンクションなどのリンクファイル・フォルダは探索しません。
  • 探索先と出力先が同じ、または出力先が探索先を含む親フォルダの場合はエラーになります。
  • 読み取り・コピーに失敗した項目はエラーを表示し、可能な残りの項目を続行します。収集記録に未コピーの行が残った場合は、問題を解消して再実行できます。
  • 終了コードは成功時0、処理エラー時1、引数の使い方が不正な場合2です。
  • Windowsやファイルシステムのパス長・アクセス権制限がある場合は、表示されたパスを確認してください。
収集結果の例: 新規 10 / 更新 2 / スキップ 30 / エラー 0
更新日時で判断するため、収集先を手作業で編集して新しい日時になったファイルは保護されます。
