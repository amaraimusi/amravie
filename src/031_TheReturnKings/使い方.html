THE RETURN OF THE KING / TheReturnKings

王の帰還

四つの種族。三つの誓い。一つの帰る場所。
ドット絵の世界を探索し、仲間と共に失われた王国へ帰る、短編ファンタジーRPG。

1. はじめかた

Python 3.9 と pygame が必要です。初回のみ、このフォルダで次のコマンドを実行してください。

py -3.9 -m pip install -r requirements.txt

「起動.bat」をダブルクリックするとゲームが始まります。コマンドから起動する場合：

py -3.9 main.py

タイトルで「はじめから」または「旅のつづき」を選びます。インターネット接続は初回のpygame導入時のみ必要です。ゲーム本体に通信機能はありません。

想定環境：Windows、Python 3.9。画面は960×640を基準にウィンドウへ拡縮します。日本語表示にはWindows標準のメイリオ等を使用します。

マウスは使用しません。人や物に隣接して決定してください。建物には入らず、玄関前の宿屋・道具屋の人と話します。

3. 冒険の進め方

王子アルトは、王城を奪った空王ヴァルドに立ち向かいます。最初は村の北にいる長老を訪ねてください。森、山道、湿原の三つの土地で仲間と出会い、北端の祭壇にいるボスを倒すと、次の地域へ進めます。

各地域の北端の道を歩くと先へ、南端を歩くと前の地域へ移動します。矢印のそばで決定しても移動できます。村では敵に遭遇しません。クリア後も世界を探索できます。

  • 祈りの泉：水色の結晶。全員のHP・MPを無料で全回復し、自動セーブします。各マップ右側の南寄りにあります。
  • 宿屋：村の左上。無料で全回復・自動セーブ。
  • 道具屋：村の右上。薬草・魔力の雫の購入と、全員の装備強化ができます。強化は各5段階まで。後から加入する仲間も強化を引き継ぎます。
  • 宝箱：各マップに2個。薬草とお金が入っています。一度だけ取得できます。
  • 冒険手帳：Esc → 冒険手帳で次の目的を確認できます。

4. 戦闘と成長

生きている仲間が順番に行動し、その後で敵が攻撃します。↑↓でコマンドを選び、決定してください。攻撃や道具は、続けて対象を選んで決定します。対象選択はXで戻れます。敵の行動後はZで次のターンへ進みます。

行動効果
攻撃敵1体に通常攻撃。消費なし。
アルト / 王家の光6MP。全員のHPを回復。戦闘不能の仲間も復帰。
リーフ / 風の矢5MP。敵1体へ強力な攻撃。
ボルグ / 砕岩撃5MP。敵1体へ強力な攻撃。
ピピン / 星の歌6MP。全員のMPを回復。
防御そのターンの被ダメージを約1/4に軽減。
薬草1個使用。味方1人のHPを65回復。戦闘不能にも有効。
魔力の雫1個使用。味方1人のMPを24回復。
逃げる通常戦闘から確実に離脱。ボス戦では使用不可。

ボスは3ターンごとに全体大技を使います。予兆が表示されたら防御しましょう。勝利すると全員が経験値を獲得し、レベルが上がるとHP・MPが全回復します。ボスを倒したときも全回復します。

全滅したらZで村へ戻れます。所持金を20%失いますが、仲間・成長・誓印・取得済みの宝箱は残ります。

5. セーブとロード

探索中にEsc → セーブ →「記録1〜3」で保存します。既存の枠を選ぶと、その枠を上書きします。残したい記録があるときは別の枠を選んでください。ロードでは「自動」と「記録1〜3」の計4枠から選べます。

地域の移動、仲間の加入、長老の使命、宿屋・泉での回復、戦闘勝利、探索中の終了、F5で自動セーブされます。自動枠は随時上書きされます。手動3枠は自動保存では変更されません。「はじめから」で新しく始めても手動枠は残ります。

保存先はゲームと同じフォルダの saves です。バックアップするときは、このフォルダを丸ごとコピーしてください。プレイ時間・場所・仲間・持ち物・進行・宝箱を保存します。

戦闘途中の保存はできません。戦闘中にウィンドウを閉じた場合、直前の記録から再開します。自動保存で問題が起きたときは画面上の通知を確認し、書き込み可能なフォルダへゲームを移してください。

6. 攻略の手引き

進行がわからないとき（ネタバレあり）
  1. 黎明の村：中央の道を北へ進み、長老と話す。宝箱と宿屋・道具屋にも寄りましょう。
  2. 翠緑の森：入口から少し北のリーフに話し、仲間に。通常戦闘で少し成長してから、北の守護獣を倒す。
  3. 鉄火の山道：ボルグを仲間にして、熔炉の巨人を倒す。アルトは回復役、他の二人は技を中心に戦うと安定します。
  4. 星影の湿原：ピピンを仲間に。星の歌でMPを補いながら、星を呑む竜を倒す。
  5. 白銀の王城：三つの誓印と四人の仲間で空王ヴァルドに挑む。3ターンごとの大技を防ぎ、王家の光で立て直しましょう。

難しいときは泉の近くで通常戦闘を繰り返すか、村へ戻って武器と防具を強化してください。

7. 困ったとき

  • 「No module named pygame」：起動に使うPythonで py -3.9 -m pip install -r requirements.txt を実行してください。
  • 「py」が見つからない：Python 3.9の実行ファイルを使用して python main.py で起動できます。pygameも同じPythonへインストールしてください。
  • 音が出ない：Mキーとシステム音量を確認してください。音声デバイスやMP3が利用できなくても無音でプレイできます。
  • ロードできない：別の記録枠を確認してください。壊れた記録は読み込まず、現在の進行を維持します。
  • 道が通れない：木・岩・水・建物は通れません。Tabで地図を開き、明るい道を辿ってください。
  • フォントが四角になる：メイリオ等の日本語フォントがあるWindows環境をご利用ください。

素材と動作検証

キャラクター・地形・敵・UI効果音はこのゲーム用のオリジナルです。画像はプログラム内で描画するため、追加画像のダウンロードは不要です。物語もオリジナルで、既存作品とは無関係です。

BGMは同梱の提供素材を使用します：Sous le pommier BGM.mp3、アゲハチョウの庭園 BGM.mp3、鉄と火の歌BGM.mp3、波打ち際のクラゲBGM.mp3、Über den Bergen BGM.mp3、空のレースSkyWingsBGM.mp3。その他の提供MP3は変更していません。外部フォルダのイラスト・歌は使用していません。

検証用：python -m unittest -v でマップの到達性、全章戦闘進行、セーブ復元、破損記録、回復・全滅復帰、各画面の描画を確認できます。テストは一時フォルダを使用し、実際のセーブには触れません。
