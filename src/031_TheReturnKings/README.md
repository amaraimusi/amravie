# 王の帰還 / The Return of the King

Python 3.9 + pygame のオフライン短編RPG。オリジナルのドット絵、5地域、4人の仲間、4ボス、ターン制戦闘、種族別の技、成長、装備強化、宝箱、3枠の手動セーブ＋自動セーブ、エンディングを収録。

## 起動

```powershell
py -3.9 -m pip install -r requirements.txt
py -3.9 main.py
```

Windowsでは「起動.bat」をダブルクリックできます。「使い方.html」に操作・攻略・保存先を記載しています。F1でも開けます。

移動：矢印/WASD、決定：Z/Enter、メニュー：Esc/X、地図：Tab、早歩き：Shift、音声：M、自動枠への保存：F5。

## 構成

- `main.py`：描画、入力、戦闘、保存、音声
- `world.py`：世界、人物、地形生成、敵・シナリオデータ
- `BGM/`：提供された既存のMP3。変更なし
- `saves/`：初回の保存時に作成。JSONは一時ファイルを経て置換
- `test_game.py`：ユーザーの記録と分離した検証

キャラ・マップ・敵の絵と効果音はプログラムで生成したオリジナル。外部の画像素材やサービスは不要。音声の利用ができない環境でもゲーム進行は可能です。

## 検証

```powershell
python -m unittest -v
python main.py --smoke-test
```

全マップの経路探索、全ボス撃破とエンディング、加入・成長、回復と全滅復帰、セーブ往復と破損JSONの拒否、画面描画を検証します。SDLのダミーデバイスを使い、テスト用セーブは一時フォルダへ隔離します。

作業画像は指定の `../030_TheReturnKings/work/` に配置しています。ゲーム実行には不要です。
