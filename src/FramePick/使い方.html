FramePick

動画フレーム抽出ツール / Python 3.9対応

← ツール一覧へ

MP4から一定間隔で画像を取り出し、元動画のパスと実際のフレーム時刻をテキストに記録します。AIに画像の説明を依頼し、その結果を字幕データに結び付けるための素材を作ります。

準備 · 実行例 · 引数 · 出力・時刻の意味 · 困ったとき

1. 準備

Python 3.9以上とFFmpegが必要です。追加のPythonパッケージは不要です。FFmpegのbinフォルダをPATHに追加するか、--ffmpegで実行ファイルを指定してください。

PowerShellで以下のフォルダに移動します。

cd C:\Users\user\git\amravie\src\FramePick
python --version
ffmpeg -version

2. 実行例

5秒ごとに、動画の終端まで抽出します。

python frame_pick.py "E:\backup_kenji\mov\n175\100ANDRO_normalized\105_26_1003_MOV_0413.mp4"

出力先を省略すると、動画と同じ場所に 105_26_1003_MOV_0413_frames フォルダを作ります。

出力先を指定し、5秒間隔で最大3枚、幅640pxに縮小します。

python frame_pick.py "E:\backup_kenji\mov\n175\100ANDRO_normalized\105_26_1003_MOV_0413.mp4" "work\sample" --interval 5 --count 3 --max-width 640

12.5秒の位置から1枚だけPNGで取得します。小数秒を指定でき、12.5秒は12500ミリ秒です。

python frame_pick.py "movie.mp4" "work\one" --start 12.5 --count 1 --format png

10秒から30秒未満まで、2.5秒おきに抽出します。

python frame_pick.py "movie.mp4" "work\range" --start 10 --end 30 --interval 2.5

4. 出力と時刻の意味

  • frame_000001.jpg など：抽出順の画像（PNG指定時は.png）。
  • frames.txt：UTF-8 BOM付きテキスト。概要とタブ区切りの一覧です。
  • ffmpeg.log：処理ログ。問題の調査にも利用できます。

一覧の image は画像ファイル名、source_video は元動画の絶対パス、requested_ms は指定した抽出位置、actual_ms は実際に取得したフレームの時刻（ミリ秒、小数3桁）です。

時刻の原点は最初の映像フレームです。各指定時刻以降の最初のフレームを選ぶため、フレームの境界によって指定値と実取得時刻がずれます。可変フレームレートでも実際の表示時刻を記録します。字幕との対応付けには actual_ms を使ってください。音声と映像に開始のずれがある素材では別途調整が必要です。

間隔が1フレームより短くても、同じフレームを重複出力しません。取得枚数は最大枚数であり、動画が短い場合は少なくなります。終了位置を動画長より後に指定した場合も、動画終端で終了します。回転情報のある映像にはFFmpegの自動回転が適用されます。

AIには画像と対応する一覧を渡し、説明文と actual_ms を結び付けます。本ツール自体は説明文やSRTを生成しません。一定間隔のサンプルなので、短いシーンを拾いたい場合は間隔を小さくしてください。

5. 困ったとき

  • 既存データの混在を防ぐため、出力先は新規または空のフォルダに限定しています。再実行時は別のフォルダ名を指定してください。
  • 抽出位置が動画の終端以降、映像がない、動画が破損している場合はエラーになります。frames.txtとffmpeg.logを確認してください。
  • 失敗・中断時は部分的な画像やログが残る場合があります。完了表示のない出力は完成した一覧として扱わないでください。
  • パスに空白がある場合も含め、パスはダブルクォートで囲むと確実です。
  • 長い動画は先頭から順に読み取るため時間がかかります。枚数や終了位置、最大幅を指定すると処理量・出力量を抑えられます。
