# PngToumeiTool — PNG背景透明化ツール

Python 3.9 / Pillowによるコマンドラインツールです。

## インストール

このフォルダで `python -m pip install -r requirements.txt` を実行してください。

## 使い方

```powershell
python PngToumeiTool.py "E:\images"
python PngToumeiTool.py "E:\images" --tolerance 0.15
python PngToumeiTool.py "E:\images" --output "E:\transparent"
python PngToumeiTool.py "E:\images\カード.png"
```

## 引数一覧

|引数|説明|
|---|---|
|input|必須。PNGファイルまたは入力フォルダ。直下のみ対象。|
|--output / -o|出力フォルダ。指定時は元ファイル名で保存。|
|--tolerance|0.0～1.0、既定0.10。大きいほど広い色範囲を除去。|
|--help / -h|ヘルプ表示。|

追加の出力先指定を優先し、省略時は入力と同じフォルダに「元名_transparent.png」を保存します。当初案のtransparentフォルダは作成しません。元画像と同じ保存先になる指定は拒否し、既存の出力は上書きします。再処理防止のため一括処理では末尾が _transparent のPNGを除外します（単体指定は可能）。日本語パス、PNG拡張子の大小文字に対応します。

## 判定方法・注意点

各隅のRGBを固定の基準色として上下左右4方向に探索します。色差はRGBの各成分差の最大値÷255です。0は完全一致、0.10は各成分差25まで、1は全色が対象です。探索中に基準色を変えないため、徐々に異なる色へ広がることを防ぎます。閉じた輪郭内の同系色は残します。

既存の完全透明部分は維持し探索の通路にします。透明な隅の隠れたRGBは背景色候補にしません。全隅が透明なら追加の色は除去されません。条件に合わない半透明部分は透明度を維持します。出力はRGBA PNGです。

四隅に被写体がある画像や、背景と同色の被写体が背景につながる画像では、被写体が消える可能性があります。輪郭ぼかし・色かぶり除去は行いません。縁が残る場合は許容値を少しずつ調整してください。大きな画像では時間とメモリが増えます。アニメーションPNGはエラーにします。メタデータは引き継ぎません。

画像ごとのエラーは表示して残りを継続します。終了コードは全件成功0、入力エラー・一部失敗1、引数エラー2です。

## テスト

`python -m unittest discover -s tests -v`

合成画像で四隅の色、許容値、内部同系色、透明度、一括処理、元画像保護を検証します。提供画像は TestData、動作確認の出力先は work です。
