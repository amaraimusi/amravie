033 SceneTransition（シーントランジション）

指示CSVの行順にシーンイラストを連結し、切り替え効果付きのMP4を作成します。

インストール

WindowsでPython 3.9とFFmpeg（libx264とAACを含むビルド）を使います。H.265を使う場合はlibx265も必要です。FFmpegをPATHに追加するか、--ffmpeg に実行ファイルのパスを指定してください。

cd C:\Users\user\git\amravie\src\033_SceneTransition && python -m pip install Pillow

コマンドプロンプトでの実行例

付属の4枚の画像で試す例。

cd C:\Users\user\git\amravie\src\033_SceneTransition && python scene_transition.py TestData\sample.csv -o ..\work\sample.mp4

制作素材を使って音声付き動画を生成する例。

cd C:\Users\user\git\amravie\src\033_SceneTransition && python scene_transition.py "E:\backup_kenji\mov\amaraimusi_no_utabako\a058\ツール開発作業\Devlerin Yeşil Zaferi.csv" -o "..\Devlerin Yeşil Zaferi - SceneTransition.mp4" --audio "..\Devlerin Yeşil Zaferi.mp3" --overwrite
引数内容
CSV [MP4] [MP3]CSVは必須。MP4とMP3は省略可。
-o / --outputMP4保存先。省略時はCSVと同じ場所・ベース名。
-a / --audioMP3音源。省略すると無音。
--aspect-ratio既定は16:9（1920×1080）。縦長は --aspect-ratio 9:16 など。
--fps正の整数。既定は30。
--codech264（既定）または h265。
--overwrite同名のMP4を上書き。
--ffmpegFFmpegの実行ファイル名またはパス。
--help引数一覧を表示。

指示CSV

UTF-8（BOMあり・なし）で保存します。CSV自体の相対パスはコマンドの実行場所、画像・MP3・MP4の相対パスはCSVのあるフォルダが基準です。

image_path,duration_ms,transition,transition_ms
scene_002.png,1500,cut,0
scene_003.png,1300,crossfade,300
scene_004.png,1100,wipe,400
scene_005.png,1600,fadeblack,500

duration_ms は切り替え後の表示時間、transition_ms はその画像に切り替える時間です。最初の行は cut,0 を指定します。効果を空欄にすると、切り替え時間が正ならクロスディゾルブ、0ならカットです。

効果は cut（カット）、crossfade（クロスディゾルブ）、fadeblack（黒経由）、wipe（ワイプ）、slide（スライド）、zoom（ズーム）、blur（ブラー）です。

映像尺は表示時間と切り替え時間の合計をフレーム単位に丸めた長さです。音声は映像生成後にAACで組み込みます。映像と音声それぞれのトラックの長さを維持します。
