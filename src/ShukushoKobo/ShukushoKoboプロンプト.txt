PngToumeiTool 開発依頼

Python 3.9を使用して、PNG画像の背景を透明化するコマンドラインツールを作成してください。

1. プロジェクト概要

日本語名：PNG背景透明化ツール

プロジェクト名：PngToumeiTool

開発言語：Python 3.9

画像処理ライブラリ：Pillowを想定

できるだけシンプルで、扱いやすく、保守しやすいツールにしてください。

2. 基本機能

背景透明化

PNG画像の四隅のピクセルカラーを背景色（マスク色）の候補として取得する。

背景色と完全一致する色だけでなく、近似色も透明化する。

近似色の許容値を0.0～1.0の範囲で指定できるようにする。

許容値の初期値は0.10程度を想定する。

四隅からつながっている背景領域を透明化するフラッドフィル方式を基本とし、画像内部の同系色を不用意に透明化しないようにする。

既存の透明部分は維持する。

出力画像はRGBA形式のPNGとする。

ディレクトリ単位の一括処理

コマンドライン引数で入力ディレクトリを指定する。

ディレクトリ直下にあるすべてのPNG画像を処理する。

サブディレクトリは処理対象外とする。

出力ディレクトリは省略可能とする。

省略された場合、入力ディレクトリ内に transparent フォルダを自動作成する。

出力ファイル名は元のファイル名を維持する。

既存の出力ファイルは上書きする。

元画像は変更しない。

3. コマンドライン仕様

以下のような操作を想定しています。

基本実行：

python PngToumeiTool.py "E:\images"

許容値を指定：

python PngToumeiTool.py "E:\images" --tolerance 0.15

出力先を指定：

python PngToumeiTool.py "E:\images" --output "E:\transparent"

引数名や内部構成については、必要に応じて合理的に設計してください。

4. 開発方針

過度に複雑な仕組みは導入しない。

AIによる画像認識は使用しない。

Python 3.9との互換性を維持する。

外部ライブラリへの依存は最小限にする。

Windows環境での利用を想定する。

日本語のファイル名やディレクトリ名にも対応する。

エラーが発生した場合は、原因を分かりやすく表示する。

複数画像の処理中に一部の画像でエラーが発生しても、可能な限り残りの処理を継続する。

背景色の判定、近似色の許容値、フラッドフィル処理などの細かなアルゴリズムは、実用性と処理速度を考慮して適切に設計してください。
