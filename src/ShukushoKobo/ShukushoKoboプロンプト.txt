# 開発依頼：縮小工房（ShukushoKobo）

## 1. 概要

Python 3.9を使用して、画像を一括縮小するCLIツールを開発してください。

- ツール名：縮小工房
- ディレクトリ名：ShukushoKobo
- 英語表記：ShukushoKobo
- ローマ字表記：shukusho-kobo
- 開発言語：Python 3.9

主な用途は、Webサイトで使用する大量の画像からサムネイルを一括生成することです。

シンプルで使いやすく、処理速度にも配慮した汎用ツールにしてください。

## 2. 基本仕様

### 一括処理

コマンドライン引数で対象ディレクトリを指定し、そのディレクトリに含まれる画像をまとめて縮小します。

画像ファイルを一つずつ指定する方式にはしません。

### 対応画像形式

PNG、JPEG、WebPなど、一般的な画像形式に対応してください。

対応形式や画像処理ライブラリの選定は任せます。

### 縮小方法

画像の縦横比を維持して縮小してください。

縮小サイズはコマンドライン引数で指定できるようにしてください。

縮小方式、画質、形式変換などの細かな仕様は、Web用サムネイル作成に適したものを検討して実装してください。

### 出力ディレクトリ

出力ディレクトリは省略可能とします。

省略した場合は、対象ディレクトリと同じ階層に、対象ディレクトリ名を利用した新しいディレクトリを自動作成してください。

例：

対象ディレクトリ：

`C:\Users\user\git\amravie\src\ShukushoKobo\TestData`

出力ディレクトリ（自動生成）：

`C:\Users\user\git\amravie\src\ShukushoKobo\TestData_resized`

出力ディレクトリを明示的に指定した場合は、そちらを使用してください。

元画像は変更せず、縮小後の画像を出力先に保存してください。

## 3. コマンドライン仕様

対象ディレクトリを必須引数、出力ディレクトリを省略可能な引数としてください。

縮小サイズなどはオプションで指定できるようにしてください。

具体的な引数名やコマンド構成は任せます。

Windows環境で利用することを前提にしてください。

## 4. 開発方針

- Python 3.9で動作すること
- シンプルで保守しやすい構造にすること
- 大量の画像を効率的に処理できること
- 画像の品質をできるだけ維持すること
- 元画像を誤って上書きしないこと
- エラーが発生した画像があっても、可能な範囲で残りの処理を継続すること
- 処理結果をコンソールに分かりやすく表示すること
- 不必要に複雑な設計や機能を追加しないこと
