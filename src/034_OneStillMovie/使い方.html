034 OneStillMovie

1枚静止画ムービー生成ツール

MP3の曲が流れている間、1枚のイラストを表示するMP4を作ります。

準備

Python 3.9とFFmpeg（libx264対応版）が必要です。コマンドラインで ffmpeg -version が実行できるように、FFmpegをPATHに追加してください。

実行方法

このHTMLと同じフォルダでコマンドを実行します。MP3、画像、出力先の順に指定します。パスは引用符で囲めます。

python one_still_movie.py "TestData/ガガンボマンv4.mp3" "TestData/02_街の住人.png"

出力先を省略すると、上の例では TestData/ガガンボマンv4.mp4 ができます。

python one_still_movie.py "TestData/ガガンボマンv4.mp3" "TestData/02_街の住人.png" "work/試作.mp4"

出力先を指定する場合は、既存のフォルダと拡張子 .mp4 のファイル名を指定します。出力先に同名ファイルがある場合はエラーになります。

動画の仕様

映像はH.264、音声はAACです。PNGやJPEGの静止画を使用でき、元の画像サイズで出力します。幅や高さが奇数の場合、その辺に1ピクセルの余白を加えます。

python one_still_movie.py --help で引数を確認できます。
