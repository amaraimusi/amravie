Python 3.9で、Style-Bert-VITS2を利用した字幕読み上げツールを開発してください。

ツール名：
SubVoice

和名：
字幕読み上げツール


# 目的

SRT字幕ファイルを読み込み、字幕本文をStyle-Bert-VITS2で読み上げて、動画編集などでそのまま利用できる音声ファイルを生成するツールを作成してください。

単純なTTS変換ではなく、SRTに記録された各字幕の「開始タイムスタンプ」を基準にして音声を配置してください。

今回の用途では、字幕の終了タイムスタンプに無理やり読み上げを収める必要はありません。

終了タイムスタンプよりも、

- 自然な朗読速度
- 自然な間
- 聞き取りやすさ
- 朗読としてのリズム

を優先してください。

# SRTの扱い

SRTを正しく解析してください。

例：

1
00:00:03,000 --> 00:00:06,000
今日は畑の様子を見てきました。

2
00:00:08,500 --> 00:00:11,000
シカクマメが元気に育っています。


この場合、

「今日は畑の様子を見てきました。」

の音声開始位置は3.000秒、

「シカクマメが元気に育っています。」

の音声開始位置は8.500秒、

としてください。


# タイムスタンプに関する最重要仕様

SRTの「開始タイムスタンプ」を最優先してください。

終了タイムスタンプは、基本的に読み上げ速度決定には使用しなくて構いません。

字幕表示時間に音声を無理やり収めるために早口にすることは避けてください。

例：

00:00:03,000 --> 00:00:05,000

という2秒の字幕でも、自然な読み上げに4秒必要なら、4秒使って構いません。


# 次の字幕との重複について

前の字幕の読み上げが長くなり、次の字幕開始時刻までに終わらない場合があります。

デフォルトでは、読み上げ速度を不自然に上げず、各字幕の開始タイムスタンプを維持してください。

つまり必要であれば音声同士が重なることを許可してください。

ただし、重複が発生した場所はログに記録してください。

例：

WARNING:
字幕 #15 の音声が字幕 #16 の開始位置を1.24秒超過しました。

将来的な拡張を考えて、可能なら以下のモードも用意してください。

--overlap-mode allow
--overlap-mode warn
--overlap-mode avoid

ただし初期デフォルトは、自然な朗読を優先する

allow

または

warn

としてください。

avoidの場合のみ、許容範囲内で読み上げ速度を少し速める仕組みにして構いません。

極端な早口にはしないでください。


# 最終音声

各字幕の開始時刻に合わせて音声を配置し、最終的に1本の音声ファイルへまとめてください。

基本出力形式：

WAV

としてください。

例：

n175_subvoice.wav

SRTの最初の字幕が10秒から始まる場合は、先頭10秒を無音にしてください。

字幕と字幕の間についても、必要に応じて無音を配置してください。
