# JVNVモデル導入・実音声テスト結果

確認日: 2026-10-17（日本時間）

## 取得・整合性確認

配布元: https://huggingface.co/litagin/style_bert_vits2_jvnv

リビジョン: `205830ca1d49e666ddfbf2a755f0108e9cade4dd`

4種類の日本語JP-Extraモデルをttsへ配置。モデルカードを含む13ファイル、合計 1004642575 バイト。
safetensors・スタイルベクトルのSHA-256は配布元LFS値と一致。各ファイルの記録はdownload_manifest.json。
4種類とも1165個のテンソル、スタイルベクトル(7, 256)、7スタイルを確認。

## CPUでの実音声生成

Python 3.9.5 / Style-Bert-VITS2 2.5.0 / torch 2.3.1+cpu。
tts/examples/demo.srtを4モデルそれぞれで合成し、SubVoiceのCLI処理を通してWAV・クレジットTXT・ログを生成。
読み上げ本文: こんにちは。畑の様子を、字幕に合わせてお伝えします。

| モデル | WAV長（秒） | サンプルレート | 先頭無音 |
|---|---:|---:|---:|
| jvnv_f1 | 4.749 | 44100 | 0.500秒 |
| jvnv_f2 | 5.016 | 44100 | 0.500秒 |
| jvnv_m1 | 5.713 | 44100 | 0.500秒 |
| jvnv_m2 | 4.761 | 44100 | 0.500秒 |

いずれも先頭0.500秒が無音、その後に非無音の合成音声があり、クレジットにCC BY-SA 4.0が含まれることを確認。
字幕の終了1.000秒に音声を無理に収めず、自然な音声末尾まで出力しています。
ファイルはexamples/output/各プロファイル名に保存し、音声モデル一覧HTMLから試聴できます。
