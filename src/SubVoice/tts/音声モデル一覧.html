SUBVOICE / VOICE LIBRARY

音声モデル一覧と使い方

女性2声・男性2声のJVNV日本語モデル。字幕の開始位置から、自然な朗読を生成します。

4種類のモデル実行方法商用利用・クレジット配布元・確認記録

ダウンロードしたモデル

Style-Bert-VITS2用のJVNV JP-Extraモデル4種類です。同じJVNVシリーズの異なる4話者であり、4種類の別エンジンではありません。各フォルダには原本のsafetensors、config.json、style_vectors.npyを配置しています。

商用利用: CC BY-SA 4.0の条件に従う場合に可能。モデル配布ページと学習元の公式ページの両方で同ライセンスを確認しました（2026年10月17日）。条件の詳細は下記を参照してください。

スタイル: Neutral / Angry / Disgust / Fear / Happy / Sad / Surprise。Neutralでも文章に応じて感情が表れるモデルです。穏やかな朗読はNeutral・速度1.0から試してください。

SubVoiceで使う

以下はPowerShellの例です。SubVoiceの専用Python環境は導入済みです。

cd C:\Users\user\git\amravie\src\SubVoice
.\.venv\Scripts\python.exe subvoice.py "E:\backup_kenji\mov\n175\n175.srt" --model jvnv_m1

--modelを上のプロファイル名へ変えるだけで声を切り替えられます。台帳は model_profiles.json。保存先を移動してもSubVoiceフォルダからの相対位置で参照します。

短い字幕で試す

同梱の demo.srt は0.500秒から始まる1件の字幕です。表示終了は1.000秒ですが、自然な読み上げを最後まで続けます。

.\.venv\Scripts\python.exe subvoice.py "tts\examples\demo.srt" --model jvnv_f1 --output-dir "work\voice-demo\f1"
.\.venv\Scripts\python.exe subvoice.py "tts\examples\demo.srt" --model jvnv_m2 --style Happy --style-weight 0.7 --speed 0.95 --output-dir "work\voice-demo\m2"
.\.venv\Scripts\python.exe subvoice.py --model jvnv_f2 --list-styles

モデルパスを直接指定する場合

.\.venv\Scripts\python.exe subvoice.py "tts\examples\demo.srt" --model "tts\jvnv-M1-jp"

直接パス指定でも音声生成できますが、台帳のライセンス・クレジットを自動転記するには jvnv_m1などのプロファイル名を指定してください。

出力と初回準備

既定はSRTと同じ場所へ、n175_subvoice.wav、n175_subvoice_credit.txt、n175_subvoice.logを出力。既存ファイルがあれば番号付きで保存します。公開用クレジットはTXTを参照し、動画の説明欄・エンドクレジットなど見つけやすい場所へ記載してください。

CPUで実行できます。日本語BERTは4モデル共通です。この環境ではサンプル生成時に取得済みです。別環境で初めて使う際は取得します。キャッシュはSubVoice/work内です。初回は接続・ディスク容量・時間が必要です。取得済みBERTは--bert-modelで指定できます。
