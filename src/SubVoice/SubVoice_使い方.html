SubVoice 字幕読み上げツール

字幕の開始位置から、自然な朗読を。

音声モデル一覧導入使い方設定一覧出力ライセンス困ったとき

SubVoiceとは

SRT字幕をStyle-Bert-VITS2で読み上げ、動画編集に使える1本のWAVへまとめます。字幕の開始時刻を守り、終了までに無理に早口で収めません。先頭と字幕間には無音を配置します。

SRTは字幕番号・開始と終了の時刻・本文からなるテキストです。複数行本文や日本語ファイル名にも対応。UTF-8で保存してください。

導入方法と音声モデル

WindowsのPython 3.9（64bit）を利用します。CPUで動きます。初回はインターネット接続とモデル用のディスク・メモリ容量が必要です。

cd C:\Users\user\git\amravie\src\SubVoice
python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt

Style-Bert-VITS2は音声合成エンジンです。Python 3.9対応の2.5.0を利用します。音声モデルは同梱していません。配布元で利用条件を確認して取得してください。

モデルフォルダにsafetensors、config.json、style_vectors.npyを置きます。safetensorsが複数ある場合はファイル自体を指定します。初回は日本語BERTも取得します。取得済みBERTは --bert-model で指定できます。

基本的な使い方

.venv\Scripts\python.exe subvoice.py "E:\backup_kenji\mov\n175\n175.srt" --model "C:\tts\models\voice"

毎回モデルを指定しない場合は、subvoice_config.example.jsonをsubvoice_config.jsonへコピーし、実際のモデルパスに変更します。同じフォルダのsubvoice_config.jsonは自動的に読み込むので、モデル登録後はSRTの指定だけで実行できます。

.venv\Scripts\python.exe subvoice.py "movie.srt" --config subvoice_config.json
.venv\Scripts\python.exe subvoice.py "movie.srt" --model "C:/tts/models/voice" --speed 0.95 --style Neutral
.venv\Scripts\python.exe subvoice.py --model "C:/tts/models/voice" --list-styles
.venv\Scripts\python.exe subvoice.py "movie.srt" --analyze-only

読み上げ速度とスタイル

速度1.0が標準、0.9でゆっくり、1.1で速めです。スタイルはモデル固有です。Neutralの有無も一覧で確認してください。pitchとintonationは通常1.0に保ちます。

重複は既定で許可しログへ記録します。avoidは最大1.15倍まで加速を試しますが、残る重複は許可します。開始位置の移動や音声切断はしません。

読み方はdictionary.example.jsonのような単語と読みのJSONで置換できます。--dictionaryで指定してください。設定ファイルより明示的なコマンド引数が優先します。

出力ファイルとクレジット

通常はSRTと同じ場所へ、n175_subvoice.wav、n175_subvoice_credit.txt、n175_subvoice.logを保存します。WAVは44.1kHz・モノラル・PCM16です。

既存ファイルがあれば_001等の別名を使います。--overwrite指定時だけ上書きします。出力先変更は --output-dir "E:/output"。

work内の実行時一時ファイルは自動削除。--keep-workで保存できます。BERTキャッシュは再利用のため保持します。解析のみではログだけ出ます。一部字幕が失敗した場合は成功分を出力し、ログへ失敗番号を記録します。

音声モデルのライセンス

音声モデルの配布元・ライセンス・必要なクレジットを確認してください。不明な情報はUNKNOWNと記録します。商用利用可能かどうかをツールが推測することはありません。

model_profiles.jsonに正式なモデル名、path、source、license、creditを登録するとクレジットTXTへ記録します。生成音声の利用・公開時は配布元の表記条件に従ってください。エンジン自体のライセンスも別に確認してください。

エラー時の確認方法

出力先の.logに詳細と字幕番号を記録します。モデルが読めない場合は3ファイルと対応関係を、スタイルエラーは--list-stylesを確認してください。依存ライブラリ不足は専用環境でrequirements.txtを再導入します。

BERTや日本語辞書の初回取得に失敗した場合は接続と書込み権限を確認してください。CUDAエラー時は--device cpu。SRTエラーは文字コード（--encoding cp932等）・時刻・空行を確認します。書込みエラーは空き容量・権限・他アプリのファイル使用を確認します。

終了コード0は成功、1は継続不能、2は一部字幕失敗です。実音声の検証状況は同梱TEST_RESULTS.mdに記録しています。
