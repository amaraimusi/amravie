030 連番振り（RenbanFuri）

指定フォルダ直下の通常ファイルを名前の昇順で並べ、3桁以上の連番を付与します。Python 3.9以上、標準ライブラリのみで動作します。Windows向けCLIです。

使い方

PowerShellでこのツールのフォルダへ移動して実行します。空白を含むパスは引用符で囲んでください。


python renban_furi.py "E:\動画\シーン" 400 3 --dry-run

python renban_furi.py "E:\動画\シーン" 400 3

python renban_furi.py --help

必須引数は順に「ディレクトリ」「開始番号（0以上の整数）」「ステップ（1以上の整数）」です。--dry-run は予定を表示するだけで変更しません。対象が空の場合は0件で正常終了します。

並び順と既存番号

- 現在のファイル名全体をPythonの文字列順（大文字・小文字を区別）で昇順に処理します。自然数順やエクスプローラーと同一の順序ではなく、10.mp4 は 2.mp4 より前になります。

- 既存番号は先頭の半角数字3桁以上と _ の組み合わせを1回だけ除去して置き換えます。例: 007_scene.mp4 → 400_scene.mp4。02_scene.png は既存番号とみなさず 400_02_scene.png になります。

- 日付などでも 20261114_scene.mp4 の先頭部分は番号とみなします。必ずプレビューで確認してください。

- 最低3桁のゼロ埋めです。0は 000_、1000は 1000_。元の名前（既存番号部分を除く）、拡張子、内容を維持します。

- 全拡張子・隠しファイルも対象です。サブフォルダ、シンボリックリンクは対象外です。ツール自身や説明書のあるフォルダを対象にするとそれらも変更されます。

安全対策・エラー

変更先の重複や対象外の既存ファイル・フォルダとの衝突を事前確認します。同一フォルダ内の .renbanfuri-* 一時フォルダへ退避してから確定するので、対象ファイル同士の名前が入れ替わる場合も処理できます。既存ファイルは上書きしません。

通常の処理失敗・Ctrl+Cでは元の名前への復旧を試みます。権限不足や使用中のファイルなどで復旧も失敗した場合は、一時フォルダ内の recovery.json（元名・一時名・変更後名の対応表）とファイルを残し、場所をエラー表示します。強制終了・電源断では自動復旧されません。対応表を確認し、対象フォルダと一時フォルダ内のファイルを照合して手動復旧してください。一時フォルダは復旧前に削除しないでください。

対象フォルダを別のプログラムや本ツールの別プロセスで同時に変更しないでください。重要な素材はバックアップを取り、まず --dry-run で順番を確認してください。Windows以外での同時書き込みに対する保証はありません。

終了コード: 正常・確認のみは0、処理エラーは1、引数エラーは2。復旧処理外のCtrl+Cは130です。

ファイル構成とテスト

- renban_furi.py: 本体

- 使い方.html: ブラウザ用ヘルプ

- TestData/: 提供されたテスト素材（そのまま保持）

- test_renban_furi.py: 自動テスト

- work/: 作業用フォルダ


python -m unittest discover -s . -p "test_renban_furi.py" -v

python renban_furi.py TestData 400 3 --dry-run

自動テストは一時フォルダで実行し、提供素材を変更しません。
