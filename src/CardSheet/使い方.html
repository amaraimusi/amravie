CardSheet

印刷シート画像作成ツール / Python 3.9

カードイラストを指定順に並べ、印刷用のPNG・JPEG画像を1枚作成します。標準は63 × 88mmのカードを2L判（127 × 178mm）へ2列 × 2行で配置します。

準備

このフォルダで次を実行します。

python -m pip install -r requirements.txt

基本の使い方

ファイルパスは空白や日本語を含む場合も、二重引用符で囲んでください。

python card_sheet.py "カード1.png" "カード2.png" "カード3.png" "カード4.png"

出力先を省略すると、1枚目と同じフォルダに「元ファイル名_cardsheet.png」を保存します。既存ファイルは上書きしません。

指定された見本カードでの実行例

python card_sheet.py "C:/Users/user/git/cgwork/work/CardMaking/見本カード/ガガンボマン.png" "C:/Users/user/git/cgwork/work/CardMaking/見本カード/勤勉なネコ.png" "C:/Users/user/git/cgwork/work/CardMaking/見本カード/猫貴族　藤原雪丸.png" "C:/Users/user/git/cgwork/work/CardMaking/見本カード/野生の料理人ゴリラ.png" -o "work/見本シート.png"

出力先のフォルダは事前に作成してください。

オプション

指定内容
--card-size 63 88カードの幅・高さ（mm）。既定63 × 88。
--sheet-size 127 178用紙の幅・高さ（mm）。既定2L判。任意の用紙サイズも指定できます。
--format png / jpeg既定PNG。jpgも指定可。出力パスがある場合は拡張子から判定します。両方指定するときは一致させてください。
-o / --output出力ファイルのパス。
--help引数の一覧を表示。
python card_sheet.py "カード1.png" "カード2.png" "カード3.png" --format jpeg
python card_sheet.py "カード1.png" --card-size 60 85 --sheet-size 127 178 -o "work/custom.jpg"

配置と画像サイズの決め方

左上→右上→次の行の順に配置します。用紙に入る列数・行数は実寸から計算します。3枚なら最後の枠は白地、標準設定で5枚以上なら5枚目以降を読み込まず無視します。カードの回転や複数シートへの分割はしません。

1枚目の画像幅 ÷ カード幅mmを基準のpx/mmとし、用紙幅・高さに掛けて四捨五入します。例えば1枚目の幅が630pxなら、シートは1270 × 1780px、カードは630 × 880pxです。1枚目の高さは基準にせず、全カードを指定実寸の縦横比へ伸縮します。切り抜きはしません。EXIFの向きを反映した画像幅を使用します。

カード間の隙間はなく、配置枠全体を用紙の中央へ置きます。標準設定の余白は左右約0.5mm・上下約1mmです。透明部分と未使用枠は白色です。端数丸めにより最大約1pxの差が生じます。印刷用の解像度情報（DPI）も保存します。

実寸で印刷するには

印刷時は用紙を2L判に設定し、「実際のサイズ」「100%」を使用してください。「用紙に合わせる」「フチなし拡大」等はカード実寸を変えることがあります。プリンターの印刷不可領域で端が欠ける場合があります。まず試し刷りして定規で確認してください。裁断線・塗り足しは付けません。

エラーについて

入力画像の破損、出力フォルダが存在しない、出力済みファイルの重複、カードが1枚も入らない用紙サイズ等はエラーになります。正の有限なmm値が必要です。出力は8000万画素までです。入力画像は変更しません。
